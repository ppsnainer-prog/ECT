# ЕЦТ Скрипты — первая версия

Сайт для хранения скриптов операторов **Единого центра телефонии (ЕЦТ)**.

## Возможности

- **Скрипты** — создание, редактирование, удаление, поиск
- **Отработки** (возражения / типовые ответы) — к каждому скрипту
- **Штрафы** — к каждому скрипту
- **Автокаталог** — встроенный iframe + ссылка на https://kowmarikk0-max.github.io/car/
- **Тёмная / светлая тема**
- **Экспорт / импорт** JSON (бэкап и перенос между устройствами)
- Данные хранятся **локально в браузере** (localStorage) — без сервера

## Как запустить

### Локально
Просто откройте `index.html` в браузере (двойной клик или через Live Server).

Или через простой сервер:
```bash
npx serve .
# или
python -m http.server 8080
```

### GitHub Pages
1. Создайте репозиторий
2. Загрузите `index.html`, `style.css`, `app.js`
3. В Settings → Pages выберите ветку `main` / root
4. Сайт будет доступен по адресу `https://USERNAME.github.io/REPO/`

## Структура

```
index.html   — разметка
style.css    — стили (легко кастомизировать цвета в :root)
app.js       — вся логика + localStorage
```

## Кастомизация

- Цвета и тема — в начале `style.css` (`:root` и `[data-theme="light"]`)
- Демо-скрипты — функция `getDemoScripts()` в `app.js`
- Блоки на главной — можно менять разметку в `renderHome()`
