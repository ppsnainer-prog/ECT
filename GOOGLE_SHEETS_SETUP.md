# Подключение Google Таблицы к ЕЦТ Скрипты

Таблица: https://docs.google.com/spreadsheets/d/10gitlvnBGl9i-wXtBZU3yfSCtu5SiIfitKAMeu0GweA/edit

## v2.5 — общие отработки и автокаталог

- **Общие отработки** хранятся в `data!E1` (если JSON очень длинный — лист `shared_chunks`).
- На сайте: **Отработки** → «+ Общая отработка» → отметить категории скриптов.
- В карточке скрипта блок **📚 Общие** показывает библиотеку для категории скрипта.
- Кнопка **↪ в скрипты** копирует общую отработку во все скрипты этих категорий.
- **Автокаталог**: файл `catalog.html` в корне сайта (не iframe на чужой GitHub) — быстрее, можно править.
- После замены `Code.gs`: **Развернуть → Новая версия** (URL тот же).

## Почему огромный скрипт не сохранялся

В Google Таблице **одна ячейка = максимум 50 000 символов**.
Старый код писал ВСЕ скрипты в ячейку **A1** — длинный текст из Word туда не влезает, запись молча падает.

Новый `Code.gs`:
- лист **scripts** — один скрипт = одна строка
- лист **chunks** — куски текста длиннее 40 000 символов
- лист **data** — короткая сводка + **E1** общие отработки

Сайт по-прежнему шлёт/читает один JSON. Нарезка происходит на сервере.

## Что сделать сейчас (обязательно)

1. Открой таблицу → **Расширения → Apps Script**
2. Полностью замени код на новый файл **Code.gs**
3. **Сохранить**
4. **Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть**
   - URL должен остаться тем же:
     `https://script.google.com/macros/s/AKfycbxk9hWog0sAruR4QRCM0t-oOFJTDvkHoA9mHy12ixT3dKWspy0Q2Pkiy85lJRnt_BlewA/exec`
5. Залей на GitHub Pages новый **app.js**
6. Войди как Александр (не «Общая») и сохрани большой скрипт ещё раз

Проверка: в таблице появятся листы `scripts` и `chunks`. В `data!A1` будет короткий JSON вида
`{"storage":"rows","count":N,...}` — не весь текст скрипта.

## Настройки развёртывания

- Тип: **Веб-приложение**
- Запуск от имени: **От моего имени**
- Кто имеет доступ: **Все** (Anyone)

Не создавай новое развёртывание «с нуля», если можно обновить текущее — иначе сменится URL.

---

## Как пользоваться

Редактируйте скрипты **на сайте**. Таблица — хранилище, не таблица «по строкам вручную».

Сайт → таблица: сразу при сохранении.
Таблица → сайт: автообновление ~12 сек (или кнопка синхронизации / F5).
