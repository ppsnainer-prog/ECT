# ЕЦТ — медиа через Google Drive (фото / аудио / видео)

## Что сделано

- На **Google Drive** файлы кладутся в папку **«ECT Media»** → подпапки `images` / `audio` / `video`.
- Имя файла: `{scriptId}_{дата}_{оригинальное_имя}`.
- С сайта можно **загрузить** и **удалить** (файл уходит в корзину Drive).
- В объекте скрипта хранится только мета: `script.media[]` (ссылки, driveId, kind…).
- Обычная синхронизация скриптов (Sheets) не меняется.

---

## 1. Google Drive

У вас уже есть папка **ECT Media** и внутри `images`, `audio`, `video` — отлично.

Папка `scriptId` не обязательна (код её не использует). Можно оставить или удалить.

Код ищет папку **по имени** «ECT Media» в корне вашего Диска (аккаунт, от которого развёрнут Apps Script).

## 2. Apps Script (обязательно)

Проект:  
https://script.google.com/u/0/home/projects/1h4149EQjdKg0gDRBL6xa7_4AmKv7VhPxKHfmP8q3IvtM2Z8_26bZ35dm/edit

### Шаги

1. Откройте проект → файл **Code.gs**.
2. **Полностью замените** содержимое на файл `Code.gs` из этого архива.
3. **Сохранить** (Ctrl+S).
4. **Развернуть → Управление развёртываниями** → карандаш у текущего веб-приложения → **Новая версия** → **Развернуть**.
   - URL должен **остаться тем же** (тот, что в Настройках сайта).
5. При первом запуске Google попросит разрешить доступ к **Google Drive** — нажмите «Разрешить» / «Advanced» → «Go to … (unsafe)» если появится.

### Проверка

В браузере откройте (подставьте свой URL exec):

```
https://script.google.com/macros/s/ВАШ_ID/exec?op=mediaInfo
```

Должен вернуться JSON вида:

```json
{
  "ok": true,
  "root": { "id": "...", "name": "ECT Media", "url": "..." },
  "subfolders": { "images": {...}, "audio": {...}, "video": {...} }
}
```

Если ошибка про Drive — проверьте, что скрипт запущен **от вашего имени** и вы дали доступ к Drive.

## 3. Сайт (GitHub Pages)

Файлы в архиве:

| Файл | Куда |
|------|------|
| `Code.gs` | только в Apps Script (см. выше) |
| `MEDIA_FRONTEND.js` | код вставить в `app.js` |
| `MEDIA_STYLE.css` | стили в конец `style.css` |
| `README_MEDIA.md` | эта инструкция |

### 3.1. Стили

Откройте `style.css` на GitHub → в **конец файла** скопируйте всё содержимое `MEDIA_STYLE.css`.

### 3.2. Логика (`app.js`)

1. Откройте `app.js`.
2. В **конец файла** (перед самой последней строкой, если есть IIFE — внутри неё) вставьте **весь** код из `MEDIA_FRONTEND.js`.

3. Найдите обработчик кликов `switch (… data-action …)` (там уже есть `case 'edit-script':`, `case 'delete-ref-media':` и т.д.) и **добавьте**:

```js
    case 'delete-script-media':
      deleteScriptMedia(el.dataset.sid, el.dataset.mid);
      break;
```

4. Найдите место, где вешается `document.addEventListener('click', …)` (или аналог) и **рядом** добавьте обработчик смены файла:

```js
document.addEventListener('change', function (e) {
  const inp = e.target && e.target.closest && e.target.closest('[data-action-change="upload-script-media"]');
  if (!inp || !inp.files || !inp.files[0]) return;
  const sid = inp.dataset.sid;
  uploadScriptMedia(sid, inp.files[0]).then(function () {
    inp.value = '';
    try { render(); } catch (_) {}
  });
});
```

5. В функции **`renderScriptDetail`** найдите разметку боковой колонки (`.crm-side` / блоки «Отработки», «Штрафы») и **вставьте** вызов:

```js
${renderScriptMediaBlock(script)}
```

Например сразу после блока с отработками или в конце `.crm-side`.

### 3.3. Залить на GitHub

- Обновлённые `app.js` и `style.css` → commit → push на ветку, с которой крутится GitHub Pages.
- Подождите 1–2 минуты, обновите сайт с Ctrl+F5.

## 4. Как пользоваться

1. Войдите как **Александр** (или другой с правами редактирования).
2. Откройте любой скрипт.
3. В блоке **«📁 Медиа»** нажмите **«+ Файл»** → выберите фото / аудио / видео.
4. После загрузки появится превью. Файл лежит на Drive в нужной подпапке.
5. **Удалить** — кнопка на карточке: файл исчезает с сайта и уходит в **корзину** Drive.

Метаданные (`script.media`) синхронизируются вместе со скриптом через Google Sheets, как и раньше.

---

## 5. Ограничения

| Параметр | Значение |
|----------|----------|
| Размер файла | Рекомендуется до **~12 МБ** (base64 + лимиты Apps Script) |
| Удаление | В **корзину** Drive (можно восстановить 30 дней) |
| Доступ по ссылке | Anyone with the link → Viewer |
| Права | Только аккаунты с `canEdit()`, не «Общая» |

Большие видео лучше грузить вручную на Drive и вставлять ссылку в текст скрипта.

## 6. Если что-то не работает

1. `?op=mediaInfo` — папка находится?
2. В консоли браузера (F12) есть ошибки fetch / CORS?
3. В Apps Script → **Выполнения** — смотрите логи ошибок.
4. URL в Настройках сайта совпадает с URL развёртывания?

При необходимости можно передать ID папки «ECT Media» явно (заменить поиск по имени на `DriveApp.getFolderById('...')` в `getMediaRootFolder_`).
