ЕЦТ — медиа через Google Drive (готовые файлы)

============================================
1) APPS SCRIPT (обязательно)
============================================
Откройте:
https://script.google.com/u/0/home/projects/1h4149EQjdKg0gDRBL6xa7_4AmKv7VhPxKHfmP8q3IvtM2Z8_26bZ35dm/edit

- Полностью замените Code.gs на файл Code.gs из этого архива
- Сохранить
- Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть
- При запросе разрешите доступ к Google Drive

Проверка (подставьте свой exec URL):
  .../exec?op=mediaInfo
Должен вернуть ok:true и папку ECT Media
(ID папки уже прописан: 13OvqOwJjjJT-ahT5spskqSA0kU3GSINF)

============================================
2) GITHUB (сайт)
============================================
Замените в репозитории файлы:

  app.js     ← из этого архива (уже с медиа)
  style.css  ← из этого архива (уже со стилями)

Остальные (index.html, catalog.html) можно не трогать, если не менялись.
Code.gs на GitHub класть НЕ обязательно (он для Apps Script).

Commit + push → обновить страницу сайта (Ctrl+F5).

============================================
3) КАК ПОЛЬЗОВАТЬСЯ
============================================
Откройте любой скрипт → слева блок «📁 Медиа» → «+ Файл».
Удаление с сайта также удаляет файл с Drive (в корзину).

Лимит файла ~12 МБ.
