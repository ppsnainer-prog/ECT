ЕЦТ — внешний автокаталог (v2.7.28)

Что делает:
- Если в вашем каталоге авто не найдено (или найдено мало),
  при поиске подгружаются модели из бесплатной базы cars-base.ru
  (425+ марок, в т.ч. BYD и другие китайские).
- Можно открыть карточку, перейти на Авто.ру / Дром,
  добавить авто в свой каталог (кнопка «В каталог»).

Файлы для загрузки на GitHub Pages (в корень репозитория ECT):
1) catalog-external.js   — новый
2) app.js                — обновлённый
3) index.html            — подключает catalog-external.js
4) config.js             — version 2.7.28
5) style.css             — чуть стилей для внешних карточек

Как проверить:
1. Откройте Автокаталог
2. Введите модель, которой нет у вас (например: «Chazor» или «Zeekr 001»)
3. Ниже появится блок «Внешний каталог»
4. Откройте карточку → «Авто.ру» / «Добавить в мой каталог»

Важно:
- Первый поиск может занять 1–3 сек (скачивается база ~1 МБ, потом кэш в localStorage на 7 дней).
- Цены и комплектации из внешнего источника — справочные; точные данные уточняйте на Авто.ру.
